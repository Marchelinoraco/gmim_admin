Keputusan AD-1 · Subdomain vs Path

Path-based

DIPILIH · MVP
gmim-keuangan.id/g/bethesda
  • ✅ Infra sederhana (1 domain, 1 sertifikat)
  • ✅ Dekat dgn kode API kini (/gereja/{id})
  • ✅ Login same-origin, tanpa OIDC/handoff/JWT
  • ✅ Fokus energi ke inti produk & operasional
  • ➖ Isolasi origin lebih lemah → dijaga server (Global Scope)

Subdomain

MASA DEPAN
bethesda.gmim-keuangan.id
  • ✅ Isolasi per-origin (cookie/storage terpisah)
  • ✅ Branding per gereja, custom domain mudah
  • ⚠️ Butuh wildcard DNS + TLS
  • ⚠️ Login lintas-origin perlu redirect OIDC
  • 🔮 Aktifkan saat tenant banyak / butuh isolasi origin

Keputusan: path-based dulu (KF-2)

Backend sudah path-based & login same-origin lebih sederhana. Model data netral terhadap pilihan URL (slug/gereja_id sudah jadi konsep tenant), jadi peralihan ke subdomain di masa depan tidak membongkar model data — hanya tambah ResolveTenant dari host + DNS/TLS/CORS.
