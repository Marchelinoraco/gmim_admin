Arsitektur GMIM
Cetak Biru · SaaS Multi-Tenant

Buku Kas Digital Multi-Gereja GMIM

Buku kas yang sederhana & transparan untuk bendahara gereja — satu platform, banyak gereja, data terisolasi total. Login satu pintu, tiap gereja diarahkan ke ruang kerjanya. (Bukan software akuntansi double-entry.)

Vue 3 + Pinia Laravel 13 + Sanctum Path-based · modular monolith MySQL single-DB Langganan + Midtrans
✅

Keputusan Final (2026-06-04)

KF-1 · Buku kas
Single-entry, bukan double-entry. Tidak menjanjikan "seperti Accurate".
KF-2 · Modular monolith
Path-based /g/<slug>; SSO-service & subdomain ditunda.
KF-3 · Mesin langganan
trial/active/past_due/expired + penegak expiry + billing.
KF-4 · Kesiapan operasional
Backup+restore drill, observability, queue, email, lifecycle.
KF-5 · Sambungkan semua FE↔API dulu
Hentikan data dummy di gmim_manage & gmim_admin; test hijau; CI isolasi. Ini Fase 0.
