Kesiapan Operasional

"Kokoh" diuji saat insiden pertama, bukan saat demo. Ini syarat operasional sebelum go-live.

💡 Backup yang belum pernah di-restore = belum ada backup. Restore drill terjadwal adalah inti, bukan tambahan.

🗄️ Backup & Pemulihan

  • Full harian terenkripsi, retensi ≥30 hari
  • PITR (binlog) → pulih ke menit tertentu
  • Off-site / region berbeda; cakup DB + file storage
  • Restore drill tiap kuartal ke env terpisah
  • Target RPO ≤15 mnt, RTO ≤4 jam (uji)

👁️ Observability

  • Sentry (FE Vue + BE Laravel)
  • Uptime monitor + status page (/health)
  • Log terstruktur (request id, gereja_id, actor)
  • Alert: webhook gagal, queue backlog, error rate, disk

⚙️ Queue & Job

  • Redis + Laravel Horizon
  • Async: webhook Midtrans, email, ekspor, job langganan
  • Retry + backoff, dead-letter, idempoten
  • Webhook: terima cepat (200) → proses di queue

✉️ Email Transaksional

  • Provider (Postmark/SES/Mailgun/Resend)
  • SPF + DKIM + DMARC wajib (deliverability)
  • Verifikasi, reset password, invoice, pengingat langganan
  • Via queue + lacak bounce/complaint
